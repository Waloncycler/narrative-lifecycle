# 阶段门槛防伪与累积证据链裁决专家 (Stage-Gate Falsification & Cumulative Audit Skill)

本 Skill 规范了对任何市场突破宣称进行**防伪审查（Anti-Hype Audit）**与**历史累积证据链聚合评判（Cumulative Evidence Chain Evaluation）**的标准流程。坚决杜绝“单点孤立判定导致漏掉质变”，保护系统评级的客观真实性。

---

## 1. 累积证据链聚合评判机制 (Cumulative Evidence Aggregation)

在对任何新增事件进行定级审查时，**严禁脱离历史孤立评判，必须调取该题材在 SQLite 中的全量历史已入库证据链**，执行如下复合判定：

```
[历史已有证据基线 (Historical Baseline)] ➕ [今日新增增量事实 (Incremental Fact)]
                                  │
                                  ▼
                 【 4 大累积门槛复合达成度矩阵 】
┌───────────────────────────────────────────────────────────────┐
│ 1. 累计商业客户数 (Cumulative Paying Clients)：去重统计 >= 3 家  │
│ 2. 累计交付/合同规模 (Cumulative Revenue Scale)：近12个月 >= 1 亿│
│ 3. 多源独立印证度 (Cross-Source Multi-Pillars)：覆盖3大独立领域 │
│ 4. 持续稳定运行期 (Temporal Stability)：连续无安全事故 >= 6 个月│
└───────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
        [ 输出：量变引发质变裁决 (Cumulative Breakthrough Verdict) ]
```

## 2. S0~S7 核心定级底线与累积审查表

| 阶段 | 阶段定义 | 必须达成的累积硬核门槛 (Cumulative Prerequisites) | 必查权威数据源与防伪审查 (Data Source Verification) |
| :--- | :--- | :--- | :--- |
| **S0** | 概念萌芽 / 假说期 | 顶级期刊（Nature/Science）论文发表、开源架构发布、全球领袖公开确立技术范式。 | arXiv、HuggingFace、GitHub、领袖第一人称专线。 |
| **S1** | 实验室原理验证 | 实验室同等环境可复现数据、学术机构独立背书。 | 严禁单方面公关宣称，必须查验国家知识产权局 (CNIPA) 发明专利或同行评议文献。 |
| **S2** | 工程样机成型 | 原型机公开测试数据、确定技术参数与路线（生物医药须取得 **CDE 临床试验 CTR 登记号并启动 I 期临床**）。 | 中国药物临床试验登记平台 (Chinadrugtrials) CTR 登记号、公开参数白皮书。 |
| **S3** | 政策立项 / 顶层催化 | 国家级专项规划、国家标准立项、首台套补贴、进入关键性 II/III 期临床。 | 中国政府网 (Gov.cn) 国务院令、发改委 (NDRC)/工信部 (MIIT) 产业红头文件、CDE II/III 期临床公示。 |
| **S4** | 预期发酵 / 资本共振 | 顶级产业资本领投、中试线（Pilot Line）开工、**政府采购与公共工程招投标启动 (CCGP)**。 | **中国政府采购网 (CCGP)** 招标文件、巨潮 (Cninfo) 募投中试线设备采购公告。 |
| **S5** | 关键突破 / 商业示范 | 累计 >= 2 家独立商业客户**真金白银付费订单 / 中标大单**、特定场景商业试运营。 | **CCGP 中标结果公示 (中标金额 > 千万级)**、巨潮资讯法定合同公告、**微观现货价格 (Pricing) 跌破平价临界点**。 |
| **S6** | 规模化放量 / 主流验证 | 累计近12个月营收破亿、毛利率转正、交付量破千台/万套、大客户批量复购（医药取得 NDA 批件上市）。 | 上市公司经审计年报 (Cninfo/SEC)、微观产业链开工率 > 80% (TrendForce/百川盈孚)、NMPA 上市批件。 |
| **S7** | 稳态成熟 / 叙事出清 | 行业格局稳固、渗透率超 50%、龙头产生稳健净利润与分红。 | 统计局 (NBS)、海关总署 (Customs) 进出口量价稳态。 |
